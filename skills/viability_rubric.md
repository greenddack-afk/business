# 사업성 5축 채점 루브릭 (viability_rubric v1)

이 문서는 모든 에이전트 프롬프트에 **원문 그대로** 삽입된다. 채점 기준을 바꾸려면 이 파일만 고친다.

## 공통 규칙

1. 점수는 0~10 **정수**이며 **높을수록 사업에 유리**하다. 경쟁 축은 "경쟁이 약할수록 높음", 리스크 축은 "안전할수록 높음"이다.
2. **점수를 먼저 확정하고, 설명은 그 뒤에 쓴다.** 순서: ① 아래 앵커에서 해당 구간을 고른다 → ② `rubric_ref`에 구간 코드(예: `market:7-8`)를 적는다 → ③ `score`를 확정한다 → ④ 그 점수를 뒷받침하는 `rationale`을 쓴다. 설명을 쓰다가 점수를 바꾸지 않는다.
3. 구간 경계에 걸리면 **낮은 쪽**을 택한다.
4. **근거 상한**: 검색 결과로 확인된 근거(출처 URL)가 하나도 없는 축은 **최대 6점**. 9~10점은 서로 다른 출처 URL 2개 이상이 있어야 한다.
5. 숫자 근거는 검색 결과에 있는 값만 `sourced`로 쓴다. 나머지는 업종 파라미터 또는 상식 기반 `estimated`로 표기한다.
6. 응원·격려 문구는 쓰지 않는다. `rationale`은 결론 한 문장 + 근거 1~2문장이다.

## 축별 앵커

### market — 시장성 (수요 규모와 성장)
| 구간 | 기준 |
|---|---|
| 9-10 | 국내 시장 1조원 이상이거나 연 성장률 15% 이상이 출처로 확인되고, 타깃이 넓다 |
| 7-8 | 시장 1,000억~1조원 또는 연 성장률 8~15%, 출처 확인 |
| 5-6 | 시장 100억~1,000억원 또는 연 성장률 3~8%. 또는 수치가 추정치뿐 |
| 3-4 | 시장 100억원 미만 니치이거나 정체(성장률 0~3%). 수요 신호 약함 |
| 0-2 | 수요 신호를 확인할 수 없거나 축소 시장 |

### competition — 경쟁 (높을수록 경쟁이 약하고 진입에 유리)
| 구간 | 기준 |
|---|---|
| 9-10 | 직접 경쟁 제품이 없거나 1~2개, 특허·규제·네트워크 같은 진입장벽을 확보할 수 있다 |
| 7-8 | 직접 경쟁사 3~5개, 지배 사업자 없음, 차별점이 검색 결과로 확인되는 범위에서 유지된다 |
| 5-6 | 경쟁사 6개 이상이나 차별점이 일부 유효하다 |
| 3-4 | 동일·유사 기능 제품이 다수이고 저가품이 범람한다. 차별점이 이미 시장에 존재한다 |
| 0-2 | 대기업·플랫폼이 지배하고 차별점이 없다 |

### execution — 실행 (창업자 1~3명이 직접 해낼 수 있는가)
| 구간 | 기준 |
|---|---|
| 9-10 | 기성 도구로 4주 내 출시 가능, 인증·허가 불필요, 1인 가능 |
| 7-8 | 3개월 내 출시 가능, 외주·OEM 활용, 인증이 없거나 간단 |
| 5-6 | 3~6개월, 필수 인증·허가 1건 또는 OEM 협상 필요 |
| 3-4 | 6~12개월, 전문 인력·금형·다수 인증 필요 |
| 0-2 | 12개월 초과, 핵심 기술 미확보 또는 인허가 불확실 |

### profitability — 수익성 (기여이익률과 손익분기)
BEP는 월 손익분기 판매량, 기본 시나리오는 Finance가 잡은 월 판매량이다.
| 구간 | 기준 |
|---|---|
| 9-10 | 기여이익률 50% 이상, BEP가 기본 시나리오 판매량의 30% 이하, 초기투자 6개월 내 회수 |
| 7-8 | 기여이익률 35~50%, BEP가 기본 시나리오의 30~60%, 12개월 내 회수 |
| 5-6 | 기여이익률 20~35% 또는 BEP가 기본 시나리오의 60~100%. 12개월 내 회수가 빠듯하다 |
| 3-4 | 기여이익률 10~20% 또는 기본 시나리오에서 12개월 내 초기투자 회수 불가 |
| 0-2 | 기여이익률 10% 미만·음수, 또는 기본 시나리오에서 적자 |

### risk — 리스크 (높을수록 안전)
| 구간 | 기준 |
|---|---|
| 9-10 | 인명·법적 책임 요소 없음, 재고 부담 없음(주문 제작·디지털), 단일 의존 없음 |
| 7-8 | 경미한 리스크 1~2개, 보험·표준 절차로 통제 가능 |
| 5-6 | 재고·반품·단일 공급처 의존 중 2개 이상. 통제는 가능하나 손실 여지가 있다 |
| 3-4 | 인체·안전 관련 제품(전기·발열·식품·의료 인접)이거나 규제 위반 시 판매 중단 가능 |
| 0-2 | 인허가 실패 시 사업 불가, 중대 사고 한 번에 폐업 수준 |

## 에이전트별 담당 축

| 에이전트 | 채점 축 |
|---|---|
| Market | market, competition |
| Finance | profitability |
| Execution | execution, risk |
| Critic | 채점하지 않음. 조정 제안만 |

## 비평 조정 규칙 (Critic → Synthesizer)

- Critic은 점수를 직접 고칠 수 없다. 축별 `delta`를 **-2 ~ 0** 정수로 제안한다.
- Synthesizer는 `evidence_url`이 검색 풀에 실제로 있는 조정만 반영한다. 근거 URL이 없거나 풀에 없으면 버리고 `adjusted_from`을 `null`로 둔다.
- 반영 시 `adjusted_from`에 원래 점수를 기록하고, 최종 점수는 0 미만이 될 수 없다.

## 종합 등급 산식 (코드로 고정, LLM이 정하지 않는다)

가중 평균 = market×0.25 + competition×0.15 + execution×0.20 + profitability×0.25 + risk×0.15 (비평 반영 후 점수 기준)

| 가중 평균 | 등급 | 판정 |
|---|---|---|
| 8.5 이상 | A+ | 진행 |
| 8.0 이상 | A | 진행 |
| 7.5 이상 | A- | 진행 |
| 7.0 이상 | B+ | 조건부 진행 |
| 6.5 이상 | B | 조건부 진행 |
| 6.0 이상 | B- | 조건부 진행 |
| 5.5 이상 | C+ | 소규모 검증 후 재판단 |
| 5.0 이상 | C | 소규모 검증 후 재판단 |
| 4.5 이상 | C- | 보류 |
| 4.5 미만 | D | 비권장 |

일부 축이 실패(`degraded`)해 점수가 없으면, 남은 축의 가중치를 다시 나눠 평균을 내고 등급 옆에 "부분 평가"를 표시한다.
